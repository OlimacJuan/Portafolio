# Portafolio

Portafolio digital de Juan Camilo, estudiante de Ingeniería Mecánica: proyectos y una biblioteca de conocimiento (metodologías de diseño y fundamentos teóricos).

Sitio publicado: https://olimacjuan.github.io/Portafolio/

- **Agregar contenido:** lee [CONTENIDO.md](CONTENIDO.md).
- **Probar en tu computador (opcional):** instala Node.js 22 o superior, luego `npm install` y `npm run dev`, y abre http://localhost:4321/Portafolio/

Hecho con Astro, KaTeX, Mermaid.js y model-viewer. Código bajo licencia MIT; contenido bajo CC BY-NC-ND 4.0 (ver [LICENSE](LICENSE)).
